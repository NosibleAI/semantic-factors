# Security policy

Please do not report suspected vulnerabilities in a public issue. Use GitHub's private security
reporting for this repository when it is enabled, or contact NOSIBLE privately through
[nosible.com](https://nosible.com) with enough detail to reproduce the issue. Do not include API
keys, customer data, World responses, or other sensitive material in an issue, pull request, CI
log, or artifact.

Before the repository becomes public, the maintainers should confirm the preferred private
security contact and update this file if needed.

The package should never log credentials or event payloads. If a credential may have been exposed,
rotate it immediately and then investigate the exposure separately from this repository.
